Politique de confidentialité

Dernière mise à jour : 31 août 2026

UglyPadlet est une extension Chrome qui transforme les Padlets publics de l'école Élan configurés dans l'extension en lecteur vertical plus lisible avec filtres.

Données traitées

L'extension lit le contenu déjà visible sur les pages Padlet ciblées, par exemple les textes, dates, sections, images, liens, PDF et vidéos intégrées. Ces données sont utilisées uniquement pour reconstruire une interface locale plus lisible dans le navigateur.

Collecte et transmission

UglyPadlet ne collecte aucune donnée personnelle sur un serveur, ne crée aucun compte utilisateur, ne vend aucune donnée et ne transmet aucune donnée à l'éditeur de l'extension ou à des tiers.

Stockage local

L'extension peut conserver localement, dans le navigateur, les préférences de filtres afin de les retrouver lors d'une prochaine visite. Ces informations restent sur l'appareil de l'utilisateur.

Permissions

L'autorisation d'accès à l'hôte est limitée aux URLs Padlet de l'école Élan déclarées dans le manifeste. Elle est nécessaire pour lire les publications visibles sur ces pages et les afficher dans une interface verticale filtrable.

Code distant

Toute la logique JavaScript de l'extension est incluse dans le package publié. L'extension ne charge pas de script distant et n'utilise pas de code JavaScript ou WebAssembly externe pour son fonctionnement. Les contenus intégrés, comme les PDF ou vidéos YouTube présents dans les publications Padlet, restent des contenus tiers affichés par le navigateur.

Contact

Pour signaler un bug ou envoyer une suggestion, écrivez à uglypadlet@carnould.com.
