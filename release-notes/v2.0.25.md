# UglyPadlet v2.0.25

## Summary

Aligne les actions de commentaires avec les permissions Padlet lorsque l'API ne retourne pas de flag explicite.

## Changes

- Lit l'utilisateur courant et le droit de moderation depuis le starting state Padlet.
- Affiche `Modifier` et `Supprimer` quand le commentaire appartient a l'utilisateur courant.
- Affiche aussi ces actions quand l'utilisateur peut moderer le Padlet.

## Validation

- Playwright: verification qu'un commentaire de l'utilisateur courant affiche les actions meme sans flag `can_delete` explicite.
- Playwright: verification que les commentaires d'autres utilisateurs restent sans actions quand la moderation n'est pas permise.

## Screenshots

- Panneau commentaires avec actions disponibles sur le commentaire de l'utilisateur courant.
