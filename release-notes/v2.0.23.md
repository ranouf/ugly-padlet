# UglyPadlet v2.0.23

## Summary

Ameliore la navigation mobile dans la modale en rendant le swipe gauche/droite disponible sur toute la surface de l'ecran.

## Changes

- Attache Hammer.js a la modale complete plutot qu'au panneau de contenu seulement.
- Conserve une detection horizontale du geste pour garder le scroll vertical naturel.
- Met a jour le test Playwright mobile pour declencher le swipe depuis le bas de la modale.

## Validation

- Playwright: verification de la navigation gauche/droite par swipe en format mobile.
- Playwright visuel: verification que la modale mobile reste sans fleches de publication et que le swipe reste actif.

## Screenshots

- Modal mobile sans fleches de publication avec swipe actif sur la modale.
