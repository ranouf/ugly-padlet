# UglyPadlet v2.0.20

## Summary

Ajoute une action de commentaire depuis le modal quand la publication Padlet originale est disponible.

## Changes

- Affiche un bouton `Commenter sur Padlet` uniquement dans le modal.
- Ouvre la publication originale dans un nouvel onglet pour permettre l'ajout de commentaire dans Padlet.
- Masque l'action quand aucune URL de publication originale n'est disponible.
- Adapte le bouton aux formats desktop, tablette et mobile.

## Validation

- Playwright: verification de l'affichage conditionnel du bouton commentaire.
- Playwright: verification responsive du bouton dans le modal mobile.

## Screenshots

- Modal desktop avec action commentaire.
- Modal mobile avec action commentaire pleine largeur.
