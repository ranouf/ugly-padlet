# UglyPadlet v2.0.27

## Summary

Affiche la modale desktop en plein ecran et regroupe les controles de navigation avec le bouton de fermeture.

## Changes

- Etend la modale desktop sur toute la largeur et toute la hauteur de l'ecran.
- Deplace les boutons precedent/suivant dans l'entete, a gauche du bouton fermer.
- Ajoute une separation visuelle entre la navigation et l'action de fermeture.
- Conserve les fleches masquees sur mobile pour garder la navigation par swipe.
- Affiche les images seules en grand format dans la modale, sans agrandir les cartes de la liste.
- Masque les publications sans contenu utilisees comme titres de regroupement Padlet, afin de les exclure de la liste chronologique, du compteur et des modales.

## Validation

- Playwright: verification du rendu modal desktop plein ecran.
- Playwright: verification du positionnement des boutons precedent/suivant avant le bouton fermer.
- Playwright: verification qu une image seule est plus grande dans la modale que dans la carte.
- Playwright: verification qu un titre sans contenu est masque, exclu du compteur et absent des modales.
