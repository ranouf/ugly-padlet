# UglyPadlet v2.0.31

## Summary

Ouvre directement une nouvelle communication depuis son lien de notification, meme avant sa mise en cache.

## Changes

- Reconnait les identifiants numeriques utilises dans les liens de notification Padlet.
- Ouvre la publication demandee des qu'elle arrive pendant la synchronisation API en arriere-plan.

## Validation

- Playwright: reproduction d'un lien profond vers une publication absente du cache.
- Playwright: verification de l'ouverture automatique apres la synchronisation API.
- CI locale: format, lint, typecheck, release note, Jest, couverture, Playwright et build.
