# UglyPadlet v2.0.17

## Summary

Les galeries d'images affichent les images dans le lecteur sans ajouter de boutons de telechargement inutiles pour chaque fichier image.

## Changes

- Exclut les URLs d'images des liens affiches dans les cartes et les modales.
- Conserve les vrais liens web avec l'icone de visite et les PDF/fichiers avec l'icone de telechargement.
- Ajoute une validation de regression pour les galeries d'images.
- Ajoute les workflows GitHub de validation PR, build et deploy Chrome Store avec release notes.
- Ajoute `ci-build.ps1` pour reproduire localement les controles GitHub.
- Affiche le detail de couverture Jest dans le commentaire de validation PR.
- Ajoute un script reproductible pour configurer la protection de `main`.

## Validation

- Jest coverage: seuil global 90%.
- Playwright: scenarios fonctionnels et visuels existants.
- Build: generation du ZIP Chrome Store.
