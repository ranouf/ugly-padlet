# UglyPadlet v2.0.22

## Summary

Ajoute un panneau de commentaires dans la modale, avec creation, edition et suppression lorsque Padlet autorise ces actions.

## Changes

- Affiche les commentaires existants dans une colonne droite sur desktop.
- Permet de publier un nouveau commentaire depuis le bas du panneau.
- Affiche `Modifier` et `Supprimer` sous les commentaires seulement quand l'action est permise.
- Permet de modifier un commentaire inline depuis le panneau de commentaires.
- Permet de supprimer un commentaire avec confirmation.
- Recharge les commentaires a chaque ouverture ou changement de publication dans la modale.
- Garde un style discret proche des commentaires sociaux, avec actions texte sous le commentaire.
- Adapte le panneau aux formats desktop, tablette et mobile.

## Validation

- Playwright: verification de l'affichage conditionnel du panneau de commentaires.
- Playwright: verification du payload envoye a l'API Padlet de creation de commentaire.
- Playwright: verification que les actions sont masquees pour les commentaires non gerables.
- Playwright: verification de l'edition via `PATCH /api/8/comments/{commentId}`.
- Playwright: verification de la suppression via `DELETE /api/5/comments/{commentId}`.`r`n- Playwright: verification que la liste de commentaires est rafraichie a la reouverture du modal.
- Playwright visuel: verification du rendu des actions en desktop et mobile.
