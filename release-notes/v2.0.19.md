# UglyPadlet v2.0.19

## Summary

Etend UglyPadlet aux autres Padlets de l'ecole Elan.

## Changes

- Autorise l'extension sur les URLs `https://padlet.com/*/*`.
- Active le lecteur sur les pages Padlet a deux segments ou plus.
- Calcule le chemin du Padlet courant pour conserver les liens profonds.
- Isole les caches, filtres et dates de connexion par Padlet.
- Laisse le Padlet original cliquable quand le lecteur est masque.

## Validation

- Prettier: format des fichiers verifies.
- Typecheck: verification TypeScript.
- Jest: metadata du package extension.
- Playwright: scenarios fonctionnels et visuels existants.
- Playwright: verification que le Padlet original reste cliquable en mode masque.
