# UglyPadlet v2.0.18

## Summary

Ajoute un indicateur visuel pour identifier les publications apparues depuis la dernière connexion.

## Changes

- Sauvegarde une date de connexion dans le localStorage au chargement du lecteur.
- Affiche un point rouge sur la date des publications considerees comme nouvelles.
- Ajoute le nombre de nouvelles publications et la date de derniere connexion dans le resume du lecteur.
- Ajoute une option `Nouvelles` dans le filtre Communication pour afficher seulement les publications recentes.
- Ajoute un dry-run Chrome Web Store pour valider les secrets de deploiement sans publier.
- Ajoute des tests fonctionnels et visuels pour valider l'indicateur de nouvelle publication.

## Validation

- Prettier: format des fichiers verifies.
- Chrome Web Store: validation locale des credentials via `pnpm chrome-store:dry-run`.
- Playwright: scenarios fonctionnels et visuels existants.
- Playwright: la derniere connexion est simulee a aujourd'hui moins 6 jours dans les scenarios de regression des nouveautes.

## Screenshots

- Visual test screenshots are generated as CI artifacts from `test-results/` instead of being kept in source control.
