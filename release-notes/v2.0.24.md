# UglyPadlet v2.0.24

## Summary

Masque les commentaires dans la modale lorsque le Padlet original indique que les commentaires sont desactives.

## Changes

- Lit le starting state Padlet pour recuperer `wall.is_commentable`.
- N'affiche pas le panneau ni le formulaire de commentaires quand `wall.is_commentable` vaut `false`.
- Conserve le comportement existant quand le starting state Padlet n'est pas disponible.

## Validation

- Playwright: verification que le panneau de commentaires reste masque sur un Padlet non commentable.
- Playwright: verification que le panneau de commentaires continue de s'afficher quand le Padlet est commentable.

## Screenshots

- Modal sans panneau commentaires lorsque les commentaires sont desactives.
