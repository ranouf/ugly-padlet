# UglyPadlet

Cette extension Chrome transforme automatiquement le Padlet de l'ecole en une lecture verticale plus claire.

Fonctions incluses :

- affichage des publications en colonne ;
- tri par date detectee dans les communications ;
- filtre des communications deja passees, a venir ou sans date ;
- filtre par periode ;
- filtre par section detectee ;
- bouton pour revenir temporairement au Padlet original.

## Installation dans Chrome

1. Ouvre `chrome://extensions`.
2. Active le mode developpeur.
3. Clique sur `Charger l'extension non empaquetee`.
4. Choisis ce dossier : `C:\Users\cedric\OneDrive\Documents\Sources\ChromeExtensions\UglyPadlet`.
5. Va sur le Padlet de l'ecole : `https://padlet.com/elanquoideneuf/ecole-elan-2025-2026-gsult4hljk84tu3a`.

La vue lisible s'ouvrira automatiquement apres le chargement du Padlet.
